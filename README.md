## 📌 About the Project

**OpenCV.49** is a Python-based project focused on computer vision and image processing using the OpenCV library.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Abdullaeva08/Opencv.49.git
```

### 2. Open the project folder

```bash
cd Opencv.49
```

### 3. Create a virtual environment (optional)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install opencv-python numpy
```

### 5. Run the project

If your main Python file is named `main.py`, run:

```bash
python main.py
```

Replace `main.py` with your actual entry-point filename if it is different.
